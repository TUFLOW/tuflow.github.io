Overview

About this manual

This document is the User Manual for the TUFLOW Classic and TUFLOW HPC hydrodynamic computational engines.

From the 2025.0.0 TUFLOW release onwards, new features, improvements and changes between releases are provided centrally in the TUFLOW Classic/HPC Changelog. Documentation for all previous releases, including archived manuals, is available from TUFLOW Downloads Archive. A summary of default changes between releases since 2006 is provided in 18  Default Changes.

How to use this Manual

This section provides an overview of the manual structure and the navigation features available to help locate information. These instructions are only provided in this section.

Navigation

This manual is organised into chapters, which are listed in the left sidebar. Select a chapter to navigate directly to that chapter. The top of the left sidebar also contains a search box which can be used to search the entire manual.

Within each chapter, the right sidebar displays a table of contents containing headings down to level 5 (e.g. Section 1.2.3.4.5). This provides an overview of the current chapter and allows navigation to a specific section. The current section is highlighted in bold as you scroll through the chapter.

At the bottom of each chapter, there are links to the previous and next chapters (when applicable).

The navigation bar at the top of the page provides quick access to the following features:

  • Dark mode: Toggle between light and dark themes
  • PDF: View the manual as a PDF document
  • Reader mode: Collapse or expand the left and right sidebars

Searching

The search function (top of the left sidebar) searches the entire manual, including chapters, tables, appendices and references. Matching results are displayed with a short preview of the surrounding text to help identify the relevant result before navigating to it.

Cross-references are used throughout the manual to link related content, including sections, figures, tables, equations, commands, etc. Hovering over a cross-reference displays a preview of the linked content. Selecting the link navigates directly to the referenced item.

The References chapter contains a complete list of all publications and resources cited throughout the manual.

Tables

Where appropriate, tables are searchable via the use of the search box, which is located at the top right of any search enabled table. Not all tables are searchable. When text is entered into the search box, table rows are dynamically filtered to only show those that contain the search text. This allows on-the-fly condensing of large tables so that only relevant content is presented.

Tables can be sorted alphabetically (or reverse alphabetically) with respect to any column by clicking (and re-clicking) the column headers. By default, all rows are displayed, however; the number of rows displayed is selectable via the ‘Show entries’ drop down. Undisplayed rows can be accessed by clicking Previous or Next or by using the numbered navigation boxes, all of which are located at the bottom of each searchable table.

Interactive Figures

Some figures are interactive, allowing data to be explored directly within the manual. Depending on the figure, this may include inspecting individual data points, zooming and panning, or using sliders to view changes in data over time.

Note

In the PDF version of the manual, interactive figures are displayed as static images.

Commands

Commands are displayed in highlighted text and are often provided as a clickable link to their corresponding command description in their command appendix. For TUFLOW Classic/HPC, there is a separate command appendix for each control file. For example, Appendix A — TCF Commands, Appendix B — ECF Commands, etc.

The command appendices provide detailed descriptions of each command and its inputs. Each command includes a summary block containing key information such as status, solver, etc. Command inputs are then described either within individual sections or in tabulated form, depending on the complexity. The table of contents in the right sidebar provides a convenient way to browse commands and inputs within the appendices.

TUFLOW commands use a structured, colour-coded syntax that is consistent throughout the documentation.

Colour coding:

  • Blue: The command
  • Red: The operator (==)
  • Black: The input(s)/parameter(s)
  • Green: Comments (must be preceded by !)

A vertical bar (|) separates the different input options for a command. Default values are enclosed in curly brackets ({}) and user defined values are enclosed in angled brackets (<>).

For example, the following command has the default input h V or allows user defined <data_types>:

Map Output Data Types == {h V} | <data_types>   ! command definition

Map Output Data Types == h V                    ! default command inputs - used if the command is not specified

Map Output Data Types == h V d dt               ! example user defined input

Example command blocks are typically provided within scrollable code blocks. These blocks can be copied directly into a text editor when building a model control file. Select the icon in the upper right corner of the block to copy the entire command block to the clipboard. An example block is provided below:

Geometry Control File == ..\model\example_001.tgc   ! Reference the TUFLOW Geometry Control File
BC Control File == ..\model\example_001.tbc         ! Reference the TUFLOW Boundary Control File
BC Database == ..\bc_dbase\bc_dbase.csv             ! Reference the Boundary Conditions Database
Read Materials File == ..\model\materials.csv       ! Reference the Materials Definition File
