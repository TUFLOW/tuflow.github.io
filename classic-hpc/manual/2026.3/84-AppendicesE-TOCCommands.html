Appendix E — TOC Commands

The TUFLOW Operations Control (.toc) contains operating rules for structures, it is read into the .ecf using the Read Operating Controls File command. For more information on the .toc see Section 4.1.11. Using operated structures is discussed in Section 5.9. The available TOC commands are listed below. For an explanation of the command syntax, see Commands.

E.1 TOC Commands

Breach Opening == {CLOSE} | OPEN | NO CHANGE

Status: Optional - when using DF Channels
Solver: Classic and HPC

The breach status of a Dam Failure Channel. CLOSE will keep the breach fully closed, while OPEN will start the breaching process. NO CHANGE means that the DF channel operation remains unchanged. The default status is CLOSE. See Section 5.9.8.2.

Cd == {0.75 or 0.6} | <Cd>

Status: Optional - when using RO Channels and PF Channels
Solver: Classic and HPC

For RO culverts, sets the discharge coefficient used in the (Ansar M. and Nair S., 2003) equation. The default value is 0.75 for RO culverts. See Section 5.9.4.

For PF channels, sets the discharge coefficient used in the orifice flow Equation 5.23. The default value is 0.6 for PF channels.

Cd Failed == <Cd>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Cd Intact sets the weir coefficient (Cd) for the un-breached section of the DF channel, while Cd Failed sets Cd for the breached section of the DF channel. This command overwrites the default Cd values set by the Weir Type Intact/Failed command. See Table 5.24.

Cd Gate == {0.6 or 0.75} | <Cd>

Status: Optional - when using SGO, SPO Channels
Solver: Classic and HPC

Sets the discharge coefficient of the gate. For sluice gates the default value is 0.6 (see Section 5.9.5). For gated spillways the default is set to the default for Cd Spillway, which is 0.75 (see Section 5.9.6).

Cd Gate Submerged == {0.8} | <Cd>

Status: Optional - when using SGO Channels
Solver: Classic and HPC

Sets the discharge coefficient of the gate when fully submerged. The default value is 0.8. See Section 5.9.5.

Cd Intact == <Cd>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Cd Intact sets the weir coefficient (Cd) for the un-breached section of the DF channel, while Cd Failed sets Cd for the breached section of the DF channel. This command overwrites the default Cd values set by the Weir Type Intact/Failed command. See Table 5.24.

Cd Spillway == {0.75}

Status: Optional - when using SPO Channels
Solver: Classic and HPC

Sets the discharge coefficient of the spillway. Default = 0.75. Prior to the 2016-03 release the default was 0.5 due to a different version of the weir equation being used. See Section 5.9.6.

Cf == {1.0} | <Cf>

Status: Optional - when using Operational Weir Channels
Solver: Classic and HPC

Weir calibration factor. The default value is 1.0. See Section 5.9.7.

Cf Failed == {1.0} | <Cf>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the weir calibration factor for DF channels. The default values are 1.0. See Table 5.24.

Cf Intact == {1.0} | <Cf>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the weir calibration factor for DF channels. The default values are 1.0. See Table 5.24.

Define [ <structure_type> ] Control == <control_id>

Status: Required
Solver: Classic and HPC

Available structure types (<structure_type>) include: “Culvert”, “Pump”, “Q Channel”, “Sluice”, “Spillway”, “Weir”, “Pipe Failure” or “Dambreak”.

Each Define Control block consists of three sections:

  • The default settings for the control’s commands, which are usually placed at the top of the definition and prior to the logical rules. The default settings are the values used for a command in the event the command is not used within the logic rules.
  • User defined variables – see Section 5.9.1.2
  • One or more logical rules – see Section 5.9.1.3

Within the control definition, commands specific to the type of structure/device can be used to adjust the structure/device’s operation. Further information can be found in Section 5.9.1.1.

<control_id> is a unique control definition name. For a 1d_nwk channel to use the control, <control_id> must be entered into the 1d_nwk Inlet_Type attribute. As mentioned above, more than one channel can reference the same control. For example, several pumps may utilise the same operational control logic.

Use End Define to terminate the block. An ERROR occurs if End Define is not specified.

Depth Breached == <initial_breach_depth>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the initial breach status of the DF channel. Metric units (default) are metres. Using Units == US Customary, the units are feet. See Section 5.9.8.2.

Depth Collapse == <depth_collapse>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the depth that the dam crest collapse during the Period Collapse at the beginning of the dam break. The default value is zero (0). See Section 5.9.8.2.

Depth Fully Breached == <depth_fully_breached>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the height (not elevation) of the dam failure opening when fully breached. The default value is zero (0). See Section 5.9.8.2.

Discharge Curve Type == {Upstream Depth} | Head Difference | Pump

Status: Optional - when using QO Channels
Solver: Classic and HPC

Used to specify how the depth/head discharge curves are calculated in QO channels. See Section 5.9.3.

  • Upstream Depth: (default) Uses the upstream depth above the channel invert for the depth discharge curve regardless of the downstream water level.
  • Head Difference: Uses the difference in upstream and downstream water levels to calculate flow rates from head discharge curves. This option is more appropriate for hydraulic structures that experience downstream controlled flow regimes.
  • Pump: Similar to a 1D pump channel, this option uses the pumping head (i.e., downstream water level minus upstream water level to calculate flow rates from head discharge curves). The flow is always in the direction the channel is digitised. Typically, the curve has decreasing flows with increasing pumping head.

End Define

Status: Required
Solver: Classic and HPC

Ends a Define Control block of .toc commands for the operating rules applied to hydraulic structures, pumps and other controllable devices. See Section 5.9.1.1.

Ex Failed == <Ex>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets Ex (the weir flow equation exponent) for the breached section of the DF channel. See Section 5.9.8.2. This command overwrites the default Ex values set by the Weir Type Intact/Failed command. See Table 5.24.

Ex Intact == <Ex>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Ex Intact sets Ex (the weir flow equation exponent) for the un-breached section of the DF channel. See Section 5.9.8.2. This command overwrites the default Ex values set by the Weir Type Intact/Failed command. See Table 5.24.

Gate Height Fully Open == <height>

Status: Optional - when using RO, SGO, SPO Channels
Solver: Classic and HPC

For vertically moving gates the height (not elevation) of the gate when fully open above the gate’s seat. If not set, the 1d_nwk “Height” attribute is used. Metric units (default) are metres. Using Units == US Customary, the units are feet.

Gate Opening [ {} | (%) ] == [ ++ | – | {} ] | <opening> | {CLOSE} | OPEN | NO CHANGE

Status: Optional - when using Q, RO, SGO, SPO Channels
Solver: Classic and HPC

The position the gate is to be operated towards. A “++” or “–” before <opening> will incrementally open or close the gate by the value of <opening>, otherwise <opening> is taken as the absolute position. The units of <opening> are in m or ft, unless “(%)” is specified, where it is the percentage of the fully gate open position. CLOSE will start moving the gate to the fully closed position, while OPEN will start moving the gate to the fully open position. NO CHANGE means that the gate operation remains unchanged. The default setting is CLOSE.

Gate Seat Vertical Offset == <offset>

Status: Optional - when using SPO Channels
Solver: Classic and HPC

The difference in height in metres (or feet if Units == US Customary) between the spillway crest and the seat of the gate.

Gate Speed [ {} | (min) ] == <speed>

Status: Optional - when using QO, RO, SGO, SPO Channels
Solver: Classic and HPC

The speed at which the gate moves. Units are m/s or ft/s or if “(min)” is specified in m/min or ft/min. See Section 5.9.3, Section 5.9.4, Section 5.9.5 and Section 5.9.6.

Gate Type == VERTICAL UNDERFLOW | VERTICAL OVERFLOW | HORIZONTAL SINGLE | HORIZONTAL DOUBLE

Status: Optional - when using RO Channels
Solver: Classic and HPC

Sets the type of gate arrangement. VERTICAL/HORIZONTAL indicates the direction of the gate movement. SINGLE is a single gate, while DOUBLE are two gates that move in/out from either side. See Section 5.9.4.

Gate Width Fully Open == <width>

Status: Optional - when using RO Channels
Solver: Classic and HPC

For horizontally moving gates the width of the gate(s) when fully open. Units are m or ft. If not set, the 1d_nwk “Width_or_Dia” attribute is used. See Section 5.9.4.

If Event == <e1> | <e2> | <e3> | …

Status: Optional
Solver: Classic and HPC

Controls which commands to process for different events (see Appendix A).

If Scenario == <s1> | <s2> | <s3> | …

Status: Optional
Solver: Classic and HPC

Controls which commands to process for different scenarios (see Appendix A).

Ka == {0} | <value>

Status: Optional - when using Operational Weirs
Solver: Classic and HPC

Sets the abutment contraction coefficient. See Section 5.9.7.

The default value is set to zero (0) for backward compatibility. The recommended values, by USBR (1987), for the abutment contraction coefficient Ka are:

  • Square abutments with headwall at 90° to direction of flow: Ka = 0.20.
  • Rounded abutments with headwall at 90° to direction of flow, when 0.15H0\(\le\) r\(\le\) 0.5H0: Ka = 0.10.
  • Rounded abutments where r > 0.5H0, and headwall is placed not more than 45° to direction of flow: Ka = 0.0.

Ka Intact == {0} | <value>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the abutment contraction coefficient. See Section 5.9.8.2 for details.

The default value is set to zero (0) for backward compatibility. The recommended values, by USBR (1987), for the abutment contraction coefficient Ka are:

  • Square abutments with headwall at 90° to direction of flow: Ka = 0.20.
  • Rounded abutments with headwall at 90° to direction of flow, when 0.15H0\(\le\) r\(\le\) 0.5H0: Ka = 0.10.
  • Rounded abutments where r > 0.5H0, and headwall is placed not more than 45° to direction of flow: Ka = 0.0.

Kp == {0} | <value>

Status: Optional - when using Operational Weirs
Solver: Classic and HPC

Sets the pier contraction coefficient. See Section 5.9.7.

The default value is set to zero (0) for backward compatibility. The following values for the pier contraction coefficient Kp are recommended by USBR (1987):

  • Square-nosed piers with corners rounded on a radius equal to approximately 0.1 of the pier thickness: Kp = 0.02.
  • Round-nosed piers: Kp = 0.01.
  • Pointed-nose piers: Kp = 0.0.

Kp Intact == {0} | <value>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the pier contraction coefficient. See Section 5.9.8.2 for details.

The default value is set to zero (0) for backward compatibility. The following values for the pier contraction coefficient Kp are recommended by USBR (1987).

  • Square-nosed piers with corners rounded on a radius equal to approximately 0.1 of the pier thickness: Kp = 0.02
  • Round-nosed piers: Kp = 0.01
  • Pointed-nose piers: Kp = 0.0

Method == <method>

Solver: Classic and HPC

Reserved for future use

Sets which method to use for the hydraulic calculations. As of the 2013-12 release this command does not need to be applied, as it is intended for use should alternative equations become available for a structure in future releases.

Number of Piers == {0}

Status: Optional - when using Operational Weirs or DF Channels
Solver: Classic and HPC

Sets the number of piers over a weir. For operational weirs, see Section 5.9.7. For dam failure modelling, applying the USBR (1987) approach, see Section 5.9.8.2. The default value is 0.

Operation == NO CHANGE

Status: Optional - when using all Operational Structures
Solver: Classic and HPC

Keep the operation of the structure unchanged. UNCHANGED can also be used instead of NO CHANGE. This function can be applied to all operational structures types.

Orifice Height Fully Open == <height>

Status: Optional - when using PF Channels
Solver: Classic and HPC

Optional command to set the height of the piping orifice when fully breached. If omitted, the value set by 1d_nwk Height_or_WF attribute is used. See Section 5.9.8.1.

Orifice Opening == {CLOSE} | OPEN | NO CHANGE

Status: Optional - when using PF Channels
Solver: Classic and HPC

The breach status of a Pipe Failure Channel. CLOSE will keep the breach to the fully closed, while OPEN will start the breaching process. NO CHANGE means that the DF channel operation remains unchanged. The default status is CLOSE. See Section 5.9.8.1.

Orifice Shape == {Rectangular} | Circular

Status: Optional - when using PF Channels
Solver: Classic and HPC

Sets the shape of the orifice, the default shape is rectangular. See Section 5.9.8.1.

Orifice Width Fully Open == <width>

Status: Optional - when using PF Channels
Solver: Classic and HPC

Optional command to set the width of the piping orifice when fully breached. If omitted, the value set by 1d_nwk Width_or_Dia attribute is used. See Section 5.9.8.1.

Period Collapse [ {} | (min) | (s) ] == {0.0} | <period>

Status: Optional - when using PF/DF Channels
Solver: Classic and HPC

For PF channels, sets the time in hour taken to ‘shut close’ the piping failure channel after it reaches the full extend. The default value is 0 (i.e. no collapsing at the end of pipe failure). See Section 5.9.8.1.

For DF channels, sets the time in hour taken to rapidly change the dam breach opening at the beginning of the dam break. The default value for DF channels is 0 (i.e. no collapsing at the beginning dam failure). See Section 5.9.8.2.

Units are in hours by default, but minutes or seconds can be used if “(min)” or “(s)” is specified.

Period Failure [ {} | (min) | (s) ] == {0.0167} | <period>

Status: Optional - when using PF/DF Channels
Solver: Classic and HPC

For PF channels, Sets the time in hours taken to reach the full size of piping failure. The default value is 0.0166667 (i.e. 60 seconds). See Section 5.9.8.1.

For DF channels, Sets the time in hours taken to reach the full size of dam failure. The default value is 0.0166667 (i.e. 60 seconds). See Section 5.9.8.2.

Units are in hours by default, but minutes or seconds can be used if “(min)” or “(s)” is specified.

Period Opening/Closing [ {} | (min) | (s) ] == {0.167} | <period>

Status: Optional - when using all Operational Structures
Solver: Classic and HPC

The time taken to fully open a closed gate or to fully close an open gate or the time taken to start the pump up or shut it down. Units are in hours by default, but minutes or seconds can be used if “(min)” or “(s)” is specified. For example, specifying either of the commands below will set the time taken to open/close the gate to half an hour:

Period Opening/Closing == 0.5
Period Opening/Closing (min) == 30
Period Opening/Closing (s) == 1800

If this command is omitted the default opening/closing period is 0.167hrs.

This command is identical to Period Startup/Shutdown and the two can be used interchangeably.

Period Startup/Shutdown [ {} | (min) | (s) ] == {0.167} | <period>

Status: Optional - when using all Operational Structures
Solver: Classic and HPC

The time taken to fully open a closed gate or to fully close an open gate or the time taken to start the pump up or shut it down. Units are in hours by default, but minutes or seconds can be used if “(min)” or “(s)” is specified. For example, specifying either of the commands below will set the time taken to open/close the gate to half an hour:

Period Opening/Closing == 0.5
Period Opening/Closing (min) == 30
Period Opening/Closing (s) == 1800

If this command is omitted the default opening/closing period is 0.167hrs.

This command is identical to Period Opening/Closing and the two can be used interchangeably.

Pump Capacity == <flow> | <discharge_curve>

Status: Optional - when using Pumps
Solver: Classic and HPC

The flow capacity of the pump either as a constant flow or reference to a depth. If a constant flow rate, specify <flow>. If a head-discharge curve specify the name of the curve in the Depth Discharge Database.

The value is in m\(^3\)/s, or ft\(^3\)/s (if using Units == US Customary).

Pump Number == <no_pumps>

Status: Optional - when using Operational Pump Channels
Solver: Classic and HPC

Number of pumps in parallel.

Pump Operation == ON | OFF | NO CHANGE

Status: Optional - when using Operational Pump Channels
Solver: Classic and HPC

Turns the operation of the pump on or off, or keeps the current operation unchanged.

Sa Failed == <Sa>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets Sa (the Villemonte equation coefficient a) for the breached section of the DF channel. See Section 5.9.8.2. This command overwrites the default Sa values set by the Weir Type Intact/Failed command.

Sa Intact == <Sa>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets Sa (the Villemonte equation coefficient a) for the un-breached section of the DF channel. See Section 5.9.8.2. This command overwrites the default Sa values set by the Weir Type Intact/Failed command.

Sb Failed == <Sb>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets Sb (the Villemonte equation coefficient b) for the breached section of the DF channel. See Section 5.9.8.2. This command overwrites the default Ex values set by the Weir Type Intact/Failed command.

Sb Intact == <Sb>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sb Intact sets Sb (the Villemonte equation coefficient b) for the un-breached section of the DF channel. See Section 5.9.8.2. This command overwrites the default Ex values set by the Weir Type Intact/Failed command. See Table 5.24.

Side Slope (degree) == 90 | <slope_in_degree>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the angle of side slope in degree. This is used for bottom width and flow area calculation. The default value is 90°, i.e. vertical side walls. See Section 5.9.8.2.

Top Width Breached == <initial_breach_depth>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the initial breach status of the DF channel. Metric units (default) are metres. Using Units == US Customary, the units are feet. See Section 5.9.8.2.

Top Width Collapse == <top_width>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the top width that opens up during the Period Collapse. This command is optional. If not defined, the collapse width is set proportionally as Top Width Fully Breached* Depth Collapse / Depth Fully Breached. See Section 5.9.8.2.

Top Width Fully Breached == <top_width>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the top width of the dam failure channel opening when fully breached. Note that the total flow with of the DF channel is set by the 1d_nwk Width_or_Dia attribute. This value can be set smaller than the Width_or_Dia if the maximum breach width does not reach the total width of the dam crest. See Section 5.9.8.2.

Weir Height [ {} | % ] == [++| –|**| //] | <weir_height>

Status: Optional - when using Operational Weirs
Solver: Classic and HPC

The height (not elevation) of the weir above its fully down (open) state to operate towards. The % option allows the specification of the percentage of the weir height that is up (0% would indicate completely lowered and 100% completely raised).

Note that the height of the weir above the crest when fully up is set by the 1d_nwk Height_or_WF attribute.

Weir Height Speed [ {} | (min) ] == <speed>

Status: Optional - when using Operational Weirs
Solver: Classic and HPC

The speed at which the weir moves in the vertical. Units are m/s or ft/s or if “(min)” is specified in m/min or ft/min.

Weir Type Failed == <weir_type>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the weir parameters for the DF channel based on Table 5.15. The default Weir Type Intact is “WB”, and the default Weir Type Failed is “WW”. See Table 5.24.

Weir Type Intact == <weir_type>

Status: Optional - when using DF Channels
Solver: Classic and HPC

Sets the weir parameters for the DF channel based on Table 5.15. The default Weir Type Intact is “WB”, and the default Weir Type Failed is “WW”. See Table 5.24.

Weir Width [ {} | % ] == <weir_width>

Status: Optional - when using Operational Weirs
Solver: Classic and HPC

The width (not elevation) of the weir to operate towards. The % option allows the specification of the percentage of the weir width that is open (0% would indicate completely closed and 100% completely open). See Section 5.9.7.

Note that the full width of the weir is set by the 1d_nwk Width_or_Dia attribute.

Weir Width Speed [ {} | (min) ] == <speed>

Status: Optional - when using Operational Weirs
Solver: Classic and HPC

The speed at which the weir moves in the horizontal. Units are m/s or ft/s or if “(min)” is specified in m/min or ft/min. See Section 5.9.7.
