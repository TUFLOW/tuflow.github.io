    QGIS TUFLOW Plugin Documentation¶

    Welcome to the QGIS TUFLOW Plugin documentation!

    This page provides an ever growing list of documentation pages that are being moved from the TUFLOW Wiki onto a more modern platform.

    Currently, the majority of documentation is still provided on the TUFLOW Wiki which is not planned to be removed. However, as tools continue to develop, their documentation may be moved onto this platform and the wiki pages will become superseded. Notices will be added to those wiki pages when this happens.

    Tools¶

    • TUFLOW Viewer

      Use TUFLOW Viewer for viewing and querying outputs in QGIS.

    • ARR to TUFLOW

      Fetch and process data from the ARR Datahub into TUFLOW rainfall boundaries.
