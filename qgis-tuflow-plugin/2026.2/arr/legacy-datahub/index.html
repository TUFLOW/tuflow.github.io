    8. Legacy Data Hub¶

    The legacy Data Hub is only accessible via the  ARR to TUFLOW (legacy) tool.

    The 2026 v1 update of the Data Hub acts as a boundary between the new and old tools. The legacy tool  works for the legacy Data Hub, but not the 2026 v1 update. The new tool  only works for the 2026 v1 update (and later).
